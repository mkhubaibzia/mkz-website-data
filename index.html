PERSONAL WEBSITE REPORTING

MKZ Website Data

A personal reporting integration operated by Muhammad Khubaib Zia to understand the performance of websites he is authorized to manage.

What it does

The app reads Google Analytics and Google Search Console reports: website traffic, acquisition channels, search clicks, impressions, search queries, page performance, submitted sitemaps, and indexed URL status.

Read-only Google access

Google authorization grants only Analytics read access and Search Console read access. The integration does not edit website content, change Analytics settings, send Gmail messages, or submit indexing requests.

How it runs

The reporting connectors run on the operator's computer. When requested through Codex, report results are supplied to Codex for analysis and answers. This public site provides app information only; it does not offer a login form or expose website reports.

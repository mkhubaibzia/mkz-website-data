MKZ Website Data

Privacy notice

Effective 26 September 2026. This notice describes the personal MKZ Website Data integration operated by Muhammad Khubaib Zia. It covers this reporting integration, not every website the operator manages.

Data accessed

With the Google account holder's authorization, the app accesses Google Analytics account and property information and reporting data, together with Google Search Console property information, search performance, sitemap information and indexed URL inspection results. Requested permissions are analytics.readonly and webmasters.readonly. It does not request access to Gmail messages, Google Drive files or contacts.

Purpose and use

Data is used to answer the operator's website-performance questions, prepare reports, compare trends and investigate SEO or measurement issues. Access is limited to properties already available to the authorized Google account. This is a personal-use tool and is not offered as a public account service.

Processing and sharing

The connectors run on the operator's computer and request data from Google's APIs. When used with Codex, selected report results are transmitted to OpenAI's Codex service for the requested analysis and become part of the relevant conversation or generated report. OpenAI's applicable account settings, terms and privacy policy govern that service's processing. The integration does not sell Google user data or provide it to advertising or data-broker services.

Storage and retention

OAuth credentials are stored in a local directory protected by Windows file permissions. They are used for authorized API requests and are not included in report output or this public repository. Generated reports may remain on the operator's computer, and conversation data may remain in Codex until deleted according to the applicable service controls. Reports have no automatic deletion schedule in this installation.

Control, revocation and deletion

The account holder can revoke the app's access at any time through Google Account connections. Revocation stops future authorized requests; it does not erase reports already saved. Local credentials and reports can be deleted from the installation, and Codex conversations can be managed using the account's conversation and data controls. Contact the operator for help with access or deletion requests.

This information website

This static site is hosted by GitHub Pages. It contains no app analytics script, advertising tracker or Google sign-in form. GitHub may process ordinary request information under its own privacy statement. Private Analytics and Search Console reports are not published here.

Changes and contact

This notice will be updated if the integration's data use changes. Questions about this app can be sent to mkhubaibzia12@gmail.com.
